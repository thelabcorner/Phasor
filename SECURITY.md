# Security policy

Phasor is experimental software. Its SVG source validator deliberately accepts a restricted subset, but **it is not a complete general-purpose sanitizer for arbitrary untrusted SVG uploads**.

Do not publish exploit details, private keys, or sensitive data in public issues. If you discover a security vulnerability, use GitHub's private vulnerability reporting on this repository if enabled, or contact the maintainer privately through an existing trusted channel before disclosure.

For ordinary behavioral errors, use GitHub Issues with a minimal reproducible input and output. Avoid including private assets or proprietary documents.

No stable-version support guarantees have been established yet.
